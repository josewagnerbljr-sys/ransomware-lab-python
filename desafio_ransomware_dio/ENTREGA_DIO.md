# Texto para o campo "Entregar Projeto"

Projeto de Cybersecurity em Python desenvolvido para o desafio da DIO, com foco no estudo do fluxo de criptografia e recuperação de arquivos em uma simulação controlada de ransomware.

O projeto contém `encrypter.py`, `decrypter.py`, `teste.txt`, laboratório isolado em `lab_data/`, testes automatizados, documentação técnica e workflow de validação no GitHub.

A implementação foi deliberadamente limitada a arquivos sintéticos dentro do diretório `lab_data/`, sem persistência, rede, elevação de privilégio, propagação ou exclusão dos arquivos originais.
